# Versões

Cada app tem a sua versão e a sua tag (`extension/vX.Y.Z` ou `server/vX.Y.Z`). Só a extensão tem
release no GitHub (a página de onde se baixa), com o texto de
[`acerola-sync/extension/RELEASE.md`](acerola-sync/extension/RELEASE.md)
(`node scripts/release/release-notes.mjs X.Y.Z <arquivo>`). Como montar o texto está no topo dele.
O server sai pelo Komodo no merge da release na `main`.
